# Domain 06 — Surgery & Treatment Management

เจ้าของข้อมูล: Domain 06

รับผิดชอบกระบวนการผ่าตัด การทำหัตถการเฉพาะทาง และการดูแลรักษาก่อน-ระหว่าง-หลังผ่าตัดของคลินิกและโรงพยาบาลสัตว์อย่างครบวงจร ตั้งแต่การบริหารทะเบียนบริการผ่าตัดและหัตถการ ความพร้อมและการฆ่าเชื้อห้องผ่าตัด การควบคุมชุดเครื่องมือผ่าตัดแบบใช้ซ้ำและรอบ Autoclave การรับคำขอผ่าตัดจากคลินิก การประเมินความพร้อมและความเสี่ยงก่อนผ่าตัด (ASA Classification) การบริหารเอกสารความยินยอมก่อนรักษา การจัดทำแผนการผ่าตัดและแผนระงับความรู้สึก การจัดตารางห้องผ่าตัดและทีมบุคลากร เช็กลิสต์เตรียมพร้อมและความปลอดภัยก่อนผ่าตัด การระงับความรู้สึกและการเฝ้าระวังสัญญาณชีพระหว่างผ่าตัด การดำเนินการผ่าตัดและหัตถการจริง การบันทึกใช้วัสดุสิ้นเปลืองและล็อตยา บันทึกการผ่าตัดฉบับรับรอง การดูแลระยะพักฟื้น การบริหารภาวะแทรกซ้อน การจำหน่ายหรือส่งต่อไปยัง Inpatient Care และการติดตามผลหลังผ่าตัด

ทั้งนี้ Domain 06 ยึดหลัก **Single Source of Truth (SSOT)** โดยเป็นเจ้าของกระบวนการผ่าตัด หัตถการเฉพาะทาง แผนผ่าตัด ตารางผ่าตัด ยาสลบ บันทึกการผ่าตัด ภาวะแทรกซ้อน และการดูแลพักฟื้น ส่วนข้อมูลเจ้าของ/สัตว์/อำนาจลงนามยินยอมอยู่ที่ Domain 01 (`owner`), ทะเบียนห้องและตารางนัดหมายอยู่ที่ Domain 02 (`appointment`), การตรวจรักษา/คำสั่งแพทย์/เวชระเบียนหลักอยู่ที่ Domain 03 (`clinical`), ทะเบียนยา ล็อต และยอดสต็อกอยู่ที่ Domain 04 (`pharmacy`), ผลตรวจเลือดและภาพวินิจฉัยอยู่ที่ Domain 05 (`laboratory`), ราคาขายและใบแจ้งหนี้อยู่ที่ Domain 00 (`core`) และ Domain 07 (`billing`), และข้อมูลบุคลากรอยู่ที่ Domain 10 (`hr`)

## กลุ่ม Surgery Catalog, Operating Room Readiness & Sterile Instrument Kits

### ตาราง `surgery.surgical_procedure_catalogs`

**หน้าที่**: จัดเก็บทะเบียนรายการผ่าตัดและหัตถการเฉพาะทางทั้งหมดของคลินิก (แยกประเภทผ่าตัดใหญ่ หัตถการเฉพาะทาง ทันตกรรม การทำแผล) โดยผูกเชื่อมกับ `core.service_catalogs` เพื่อใช้ราคาขายกลางจาก `core.service_prices` และเพิ่มเติมคุณลักษณะเฉพาะด้านศัลยกรรม (ความซับซ้อน กลุ่มอวัยวะ วิธีระงับความรู้สึก ระยะเวลาเตรียม/ผ่าตัด/พักฟื้น และห้อง/คุณสมบัติผู้ทำที่ต้องการ) ตามข้อ 3.1

#### โครงสร้าง Field:

| `surgical_catalog_id`           | UUID         | PK, NOT NULL                           |

| `service_catalog_id`            | UUID         | FK → core.service_catalogs, NOT NULL   |
| `procedure_name`                | VARCHAR(200) | NOT NULL                               |
| `procedure_name_en`             | VARCHAR(200) | NULL                                   |
| `service_kind`                  | ENUM         | NOT NULL                               |
| `anatomical_system`             | ENUM         | NOT NULL                               |

| `default_duration_minutes`      | SMALLINT     | NOT NULL                               |
| `pre_op_prep_minutes`           | SMALLINT     | NOT NULL DEFAULT 15                    |
| `post_op_recovery_minutes`      | SMALLINT     | NOT NULL DEFAULT 30                    |

| `required_staff_qualification`  | VARCHAR(150) | NULL                                   |

#### ข้อกำหนด:

- `surgical_catalog_id`: รหัสประจำรายการผ่าตัด/หัตถการใน Domain 06 ใช้เป็น Primary Key
- `procedure_code`: รหัสบริการผ่าตัดทางธุรกิจ เช่น `SRG-SPAY-DOG`, `SRG-DENT-SCALE`, `PRC-WOUND-SUTURE`
- `service_catalog_id`: รหัสบริการกลางใน `core.service_catalogs` เพื่อเชื่อมโยงราคาบริการรายสาขาใน `core.service_prices` และส่งเรียกเก็บเงินใน Domain 07 โดยไม่สร้างตารางราคาซ้ำ
- `procedure_name` / `procedure_name_en`: ชื่อรายการผ่าตัดหรือหัตถการภาษาไทยและภาษาอังกฤษ
- `service_kind`: ประเภทการรักษา ค่าที่เป็นไปได้ คือ `MAJOR_SURGERY` (ผ่าตัดใหญ่), `MINOR_SURGERY` (ผ่าตัดเล็ก), `SPECIALIZED_PROCEDURE` (หัตถการเฉพาะทาง เช่น ใส่สายสวนปัสสาวะ ระบายของเหลว), `DENTAL_SURGERY` (ทันตกรรมและศัลยกรรมช่องปาก), `WOUND_TREATMENT` (ทำแผล/เย็บแผล/ตัดไหม), `DIAGNOSTIC_PROCEDURE` (ตัดชิ้นเนื้อ/ส่องกล้อง), `FLUID_INTERVENTION` (หัตถการให้สารน้ำเฉพาะทาง)
- `anatomical_system`: กลุ่มระบบอวัยวะ (`ABDOMINAL`, `SOFT_TISSUE`, `ORTHOPEDIC`, `REPRODUCTIVE`, `DENTAL_ORAL`, `OPHTHALMIC`, `SKIN_WOUND`, `URINARY`, `RESPIRATORY`, `NEUROLOGIC`, `CARDIOVASCULAR`, `ONCOLOGIC`, `OTHER`)
- `complexity_level`: ระดับความซับซ้อน (`LOW`, `MODERATE`, `HIGH`, `CRITICAL`)
- `default_anesthesia_type`: ประเภทการระงับความรู้สึกมาตรฐาน (`NONE`, `LOCAL`, `REGIONAL`, `SEDATION`, `GENERAL_INHALANT`, `GENERAL_INJECTABLE`, `COMBINED`)
- `default_duration_minutes` / `pre_op_prep_minutes` / `post_op_recovery_minutes`: ระยะเวลาดำเนินการโดยประมาณ เวลาเตรียมห้อง/เตรียมสัตว์ และเวลาพักฟื้นโดยประมาณ (นาที)
- `required_room_type`: ประเภทห้องมาตรฐานที่ต้องการ อ้างอิงกลุ่มค่า `appointment.rooms.room_type` ได้แก่ `SURGERY`, `TREATMENT`, `GENERAL_EXAMINATION`, `SPECIALIST_EXAMINATION`, `RECOVERY`
- `required_staff_qualification`: คุณสมบัติหรือความเชี่ยวชาญขั้นต่ำของสัตวแพทย์ผู้ดำเนินการ (ใช้อ้างอิงร่วมกับ Domain 10 HR)
- `requires_consent_form` / `requires_preop_assessment` / `requires_fasting` / `fasting_hours_recommended`: ธงระบุข้อบังคับก่อนดำเนินการ (เอกสารยินยอม, ประเมินก่อนผ่าตัด, การงดน้ำงดอาหาร)
- `pre_op_instructions` / `post_op_instructions_template`: คำแนะนำเตรียมตัวก่อนทำและแนวทางดูแลหลังทำมาตรฐาน
- `status`: สถานะ (`DRAFT`, `ACTIVE`, `INACTIVE`, `RETIRED`)
- `created_at` / `created_by` / `updated_at` / `updated_by`: ข้อมูล Audit อ้างอิง `hr.employees`

#### หมายเหตุ:

1. ต้องแยกประเภทบริการผ่าตัดออกจากหัตถการทั่วไปตามกฎข้อ 3.1
2. การแก้ไขข้อมูลในตารางนี้ต้องไม่ทำให้ Snapshot ชื่อและรายละเอียดใน `surgery_request_items`, `surgery_case_procedures` หรือ Billing ในอดีตเปลี่ยนตาม
3. `default_duration_minutes > 0` และ `pre_op_prep_minutes >= 0`, `post_op_recovery_minutes >= 0`

### ตาราง `surgery.operating_room_turnover_logs`

**หน้าที่**: จัดเก็บบันทึกความพร้อม การทำความสะอาด การฆ่าเชื้อ และการตรวจรับห้องผ่าตัดและห้องหัตถการก่อนและหลังการผ่าตัดแต่ละครั้ง อ้างอิงอัตลักษณ์ห้องจาก `appointment.rooms` (Domain 02) เพื่อไม่สร้างทะเบียนห้องซ้ำซ้อนตามข้อ 3.7 และ 6.9

#### โครงสร้าง Field:

| Column                       | Data Type    | Constraint                              |
| ---------------------------- | ------------ | --------------------------------------- |
| `turnover_log_id`            | UUID         | PK, NOT NULL                            |
| `branch_id`                  | UUID         | FK → core.branches, NOT NULL            |
| `room_id`                    | UUID         | FK → appointment.rooms, NOT NULL        |
| `surgery_case_id`            | UUID         | FK → surgery.surgery_cases, NULL        |
| `turnover_stage`             | ENUM         | NOT NULL                                |
| `performed_by`               | UUID         | FK → hr.employees, NOT NULL             |
| `verified_by`                | UUID         | FK → hr.employees, NULL                 |
| `sanitation_method`          | VARCHAR(150) | NULL                                    |
| `disinfectant_used`          | VARCHAR(150) | NULL                                    |
| `equipment_verified`         | BOOLEAN      | NOT NULL DEFAULT FALSE                  |
| `air_sterilization_verified` | BOOLEAN      | NOT NULL DEFAULT FALSE                  |
| `room_readiness_status`      | ENUM         | NOT NULL                                |
| `started_at`                 | TIMESTAMPTZ  | NOT NULL                                |
| `completed_at`               | TIMESTAMPTZ  | NULL                                    |
| `notes`                      | TEXT         | NULL                                    |
| `created_at`                 | TIMESTAMPTZ  | NOT NULL                                |

#### ข้อกำหนด:

- `turnover_log_id`: รหัสประจำรายการตรวจความพร้อม/ทำความสะอาดห้องผ่าตัด
- `branch_id` / `room_id`: สาขาและห้องผ่าตัด/ห้องหัตถการ อ้างอิง `core.branches` และ `appointment.rooms`
- `surgery_case_id`: เคสผ่าตัดก่อนหน้าหรือเคสที่กำลังจะเริ่ม (ถ้าเกี่ยวข้อง) อ้างอิง `surgery.surgery_cases`
- `turnover_stage`: ขั้นตอนการจัดการห้อง (`PRE_OPERATIVE_CHECK` ตรวจความพร้อมก่อนผ่าตัด, `POST_CASE_CLEANING` ทำความสะอาดหลังจบเคส, `DEEP_STERILIZATION` อบฆ่าเชื้อประจำรอบ, `MAINTENANCE_LOCK` แจ้งซ่อมบำรุง/ปิดห้อง, `RELEASED_READY` ปลดล็อกพร้อมใช้งาน)
- `performed_by` / `verified_by`: เจ้าหน้าที่ห้องผ่าตัดผู้ดำเนินการทำความสะอาด/ตรวจเช็ก และผู้ตรวจสอบรับรองความพร้อม
- `sanitation_method` / `disinfectant_used`: วิธีการทำความสะอาด/ฆ่าเชื้อ และน้ำยาฆ่าเชื้อที่ใช้ (เช่น UV-C, Chlorhexidine, Hydrogen Peroxide Fogging)
- `equipment_verified` / `air_sterilization_verified`: ยืนยันความพร้อมของอุปกรณ์ประจำห้องและการฆ่าเชื้อบรรยากาศห้องแล้ว
- `room_readiness_status`: สถานะความพร้อมล่าสุดของห้องหลังดำเนินการ (`READY_STERILE`, `CLEANING_IN_PROGRESS`, `CONTAMINATED_HOLD`, `MAINTENANCE_UNAVAILABLE`)
- `started_at` / `completed_at` / `notes` / `created_at`: เวลาเริ่ม-เสร็จสิ้น หมายเหตุปัญหาห้อง และเวลาบันทึก

#### หมายเหตุ:

1. ตารางนี้เก็บประวัติแบบ Append-only และห้องที่อยู่ในสถานะ `CONTAMINATED_HOLD` หรือ `MAINTENANCE_UNAVAILABLE` ต้องไม่ถูกนำมาเริ่มเคสผ่าตัดใหม่
2. สำหรับการสร้าง SQL DDL จริง ควรเพิ่ม FK `surgery_case_id → surgery.surgery_cases` ภายหลังด้วย `ALTER TABLE`

### ตาราง `surgery.surgical_instrument_kits`

**หน้าที่**: จัดเก็บทะเบียนชุดเครื่องมือผ่าตัดและอุปกรณ์ใช้ซ้ำได้ (Reusable Surgical Instruments & Sterile Packs) โดยแยกออกจากวัสดุสิ้นเปลืองของ Domain 04 (`pharmacy`) และติดตามสถานะความสะอาด/ปลอดเชื้อ วันหมดอายุการนึ่งฆ่าเชื้อ และจุดจัดเก็บพร้อมรองรับการเชื่อม Facility & Equipment ในอนาคตตามข้อ 3.14

#### โครงสร้าง Field:

| Column                        | Data Type    | Constraint                   |
| ----------------------------- | ------------ | ---------------------------- |
| `instrument_kit_id`           | UUID         | PK, NOT NULL                 |
| `kit_code`                    | VARCHAR(50)  | UNIQUE, NOT NULL             |
| `branch_id`                   | UUID         | FK → core.branches, NOT NULL |
| `facility_asset_id`           | UUID         | NULL                         |
| `kit_name`                    | VARCHAR(200) | NOT NULL                     |
| `kit_category`                | ENUM         | NOT NULL                     |
| `description`                 | TEXT         | NULL                         |
| `item_count_standard`         | SMALLINT     | NOT NULL DEFAULT 1           |
| `sterilization_method_required` | ENUM       | NOT NULL                     |
| `max_sterile_shelf_days`      | SMALLINT     | NOT NULL DEFAULT 30          |
| `last_sterilized_at`          | TIMESTAMPTZ  | NULL                         |
| `sterilization_expires_at`    | TIMESTAMPTZ  | NULL                         |
| `sterilization_status`        | ENUM         | NOT NULL                     |
| `current_storage_location`    | VARCHAR(150) | NULL                         |
| `responsible_employee_id`     | UUID         | FK → hr.employees, NULL      |
| `notes`                       | TEXT         | NULL                         |
| `created_at`                  | TIMESTAMPTZ  | NOT NULL                     |
| `created_by`                  | UUID         | FK → hr.employees, NOT NULL  |
| `updated_at`                  | TIMESTAMPTZ  | NULL                         |
| `updated_by`                  | UUID         | FK → hr.employees, NULL      |

#### ข้อกำหนด:

- `instrument_kit_id`: รหัสประจำชุดเครื่องมือผ่าตัด
- `kit_code`: รหัสประจำชุดเครื่องมือที่ไม่ซ้ำกัน เช่น `KIT-GEN-01`, `KIT-ORTHO-02`, `KIT-DENT-01`
- `branch_id` / `facility_asset_id`: สาขาเจ้าของชุดเครื่องมือ และรหัสทรัพย์สินกลางเผื่อเชื่อมระบบ Facility & Equipment Management ในอนาคต
- `kit_name` / `kit_category`: ชื่อชุดเครื่องมือและประเภท (`GENERAL_SURGERY_PACK`, `SPAY_NEUTER_PACK`, `ORTHOPEDIC_SET`, `OPHTHALMIC_MICRO_SET`, `DENTAL_SET`, `ENDOSCOPY_SET`, `SINGLE_INSTRUMENT`, `ANESTHESIA_CIRCUIT`)
- `description` / `item_count_standard`: รายละเอียดรายการเครื่องมือภายในชุด และจำนวนชิ้นมาตรฐานในชุด (ใช้ตรวจสอบ Pre-op / Post-op Count ป้องกันเครื่องมือค้างในร่างกายสัตว์)
- `sterilization_method_required`: วิธีฆ่าเชื้อที่ชุดนี้รองรับ (`AUTOCLAVE_STEAM`, `ETHYLENE_OXIDE`, `HYDROGEN_PEROXIDE_PLASMA`, `COLD_CHEMICAL`, `HIGH_LEVEL_DISINFECTION`)
- `max_sterile_shelf_days` / `last_sterilized_at` / `sterilization_expires_at`: อายุความปลอดเชื้อหลังนึ่ง (วัน) วันเวลานึ่งฆ่าเชื้อล่าสุด และวันเวลาที่หมดอายุปลอดเชื้อต้องนำไปนึ่งใหม่
- `sterilization_status`: สถานะความพร้อม/ความปลอดเชื้อ ค่าที่เป็นไปได้ คือ `STERILE_READY` (ปลอดเชื้อพร้อมใช้), `IN_USE` (กำลังใช้งานในห้องผ่าตัด), `CONTAMINATED_DIRTY` (ใช้แล้วรอการล้างทำความสะอาด), `WASHING` (อยู่ระหว่างล้าง), `AUTOCLAVING` (อยู่ระหว่างนึ่งฆ่าเชื้อ), `QUARANTINED` (กักกัน/ไม่ผ่านเทสฆ่าเชื้อ), `DAMAGED_REPAIR` (ชำรุดรอซ่อม), `RETIRED` (ปลดระวาง)
- `current_storage_location` / `responsible_employee_id`: จุดเก็บปัจจุบัน (เช่น ตู้ปลอดเชื้อ OR-1) และผู้ดูแล
- `notes` / `created_at` / `created_by` / `updated_at` / `updated_by`: หมายเหตุและข้อมูล Audit

#### หมายเหตุ:

1. ชุดเครื่องมือที่มี `sterilization_status <> 'STERILE_READY'` หรือมี `sterilization_expires_at < NOW()` ห้ามอนุญาตให้เบิกเข้าเคสผ่าตัดใน `surgical_instrument_usages` (กฎ §3.14)

- `notes` / `created_at` / `created_by` / `updated_at` / `updated_by`: หมายเหตุและข้อมูล Audit

- `assessment_sequence`: ลำดับครั้งที่ประเมินสำหรับคำขอนี้ (1, 2, ... รองรับกรณีประเมินซ้ำเมื่อสภาพร่างกายเปลี่ยนแปลงตาม §3.3)
- `assessed_by` / `assessed_at`: สัตวแพทย์ผู้ประเมินและวันเวลาที่ประเมิน
- `weight_kg_at_assessment` / `temperature_c` / `heart_rate_bpm` / `respiratory_rate_rpm` / `blood_pressure_systolic` / `blood_pressure_diastolic` / `mucous_membrane` / `crt_seconds`: ค่าสัญญาณชีพและน้ำหนัก ณ วันประเมินก่อนผ่าตัด
- `hydration_status`: ภาวะความชุ่มชื้น (`NORMAL`, `MILD_DEHYDRATION`, `MODERATE_DEHYDRATION`, `SEVERE_DEHYDRATION`)
- `cardiovascular_eval` / `respiratory_eval` / `neurologic_eval`: สรุปผลการประเมินระบบหัวใจ-หลอดเลือด ระบบหายใจ และระบบประสาท
- `allergy_reviewed` / `chronic_condition_reviewed` / `current_medications_reviewed`: ยืนยันว่าได้ทบทวนข้อมูลแพ้ยา (`clinical.pet_allergies`), โรคประจำตัว (`clinical.pet_chronic_conditions`) และประวัติยาปัจจุบันแล้ว
- `preop_diagnostic_order_id` / `lab_review_summary`: อ้างอิงคำสั่งตรวจเลือด/ภาพวินิจฉัยก่อนผ่าตัดจาก Domain 05 (`laboratory.diagnostic_orders`) และสรุปความเห็นแพทย์ต่อผลตรวจนั้น
- `asa_classification` / `asa_emergency_modifier`: ระดับความเสี่ยงทางกายภาพในการวางยาสลบ (`ASA_I` สุขภาพดีปกติ, `ASA_II` มีโรคระบบไม่รุนแรง, `ASA_III` มีโรคระบบรุนแรงจำกัดกิจกรรม, `ASA_IV` โรครุนแรงเป็นอันตรายต่อชีวิต, `ASA_V` อาการหนักคาดไม่รอดหากไม่ผ่าตัด) และตัวขยาย `E` เมื่อเป็นกรณีฉุกเฉิน
- `risk_precautions` / `management_plan`: ข้อควรระวังพิเศษและแนวทางจัดการความเสี่ยง (เช่น แก้ไขภาวะขาดน้ำก่อนดมยาสลบ)
- `assessment_status`: สถานะการประเมินตามข้อ 5.2 ค่าที่เป็นไปได้ คือ `PENDING`, `IN_ASSESSMENT`, `ADDITIONAL_TEST_REQUIRED`, `READY`, `NOT_READY`, `REASSESSMENT_REQUIRED`, `APPROVED`
- `approved_by` / `approved_at`: สัตวแพทย์ผู้รับรองความพร้อมให้เข้าผ่าตัดได้
- `notes` / `created_at` / `created_by` / `updated_at` / `updated_by`: หมายเหตุและข้อมูล Audit

#### หมายเหตุ:

1. กำหนด Unique Constraint `(surgery_request_id, assessment_sequence)` และห้ามเขียนทับผลการประเมินครั้งเดิมเมื่ออาการสัตว์เปลี่ยนแปลง ให้สร้างรอบ `assessment_sequence` ใหม่แทน (กฎ §3.3)
2. การตัดสินความพร้อมผ่าตัดต้องเกิดจากการประเมินและรับรองโดยสัตวแพทย์ (`assessed_by`/`approved_by`) ห้ามให้ระบบอนุมัติอัตโนมัติแทนวิชาชีพ

- `case_category`: ประเภทเคส (`SURGERY` ผ่าตัด, `SPECIALIZED_PROCEDURE` หัตถการเฉพาะทาง, `DENTAL` ทันตกรรม, `EMERGENCY_SURGERY` ผ่าตัดฉุกเฉิน)
- `priority_level`: ระดับความเร่งด่วน (`ELECTIVE`, `URGENT`, `EMERGENCY_STAT`)
- `patient_checked_in_at` / `anesthesia_started_at` / `incision_or_procedure_started_at` / `closure_or_procedure_ended_at` / `anesthesia_ended_at`: เวลาสำคัญในห้องผ่าตัดสำหรับคำนวณ Anesthesia Time, Skin-to-Skin Operative Time และ Room Utilization ตาม §3.20
- `actual_case_outcome`: ผลสรุปของการดำเนินการ (`SUCCESSFUL` สำเร็จลุล่วง, `COMPLETED_WITH_COMPLICATION` สำเร็จแต่พบภาวะแทรกซ้อน, `PARTIAL` ดำเนินการได้บางส่วน, `ABORTED` ยุติกลางคันเนื่องจากเหตุฉุกเฉิน, `INTRAOP_DEATH` สัตว์เสียชีวิตระหว่างผ่าตัด)
- `case_status`: สถานะเคสผ่าตัดครบตามข้อ 5.3 ค่าที่เป็นไปได้ คือ `SCHEDULED` (กำหนดเวลาแล้ว), `PREPARATION` (กำลังเตรียมสัตว์/ห้อง), `READY_FOR_SURGERY` (ผ่าน Checklist พร้อมเข้าห้องผ่าตัด), `ANESTHESIA_IN_PROGRESS` (กำลังระงับความรู้สึก), `SURGERY_IN_PROGRESS` (กำลังผ่าตัด/ทำหัตถการ), `RECOVERY` (อยู่ระหว่างพักฟื้นหลังผ่าตัด), `COMPLETED` (การผ่าตัดเสร็จสิ้น — ไม่เท่ากับสัตว์ฟื้นตัวสมบูรณ์หรือชำระเงินแล้ว), `ABORTED` (ยุติการผ่าตัดก่อนเสร็จ), `CANCELLED` (ยกเลิกก่อนลงมีด)
- `abort_or_cancel_reason` / `notes` / `created_at` / `created_by` / `updated_at` / `updated_by`: เหตุผลกรณียุติหรือยกเลิก หมายเหตุ และข้อมูล Audit (วันเวลาและผู้สร้าง/แก้ไข)

#### หมายเหตุ:

1. ต้องแยกสถานะ `case_status = 'COMPLETED'` ของการผ่าตัดออกจากการฟื้นตัวใน `postoperative_cares` และการชำระเงินใน Domain 07 เสมอ (กฎ §10.5 และ §10.6)
2. เคสที่เริ่มลงมีดหรือให้ยาสลบไปแล้ว (`ANESTHESIA_IN_PROGRESS` / `SURGERY_IN_PROGRESS`) หากจำเป็นต้องหยุดกลางคัน ให้ใช้สถานะ `ABORTED` พร้อมระบุ `abort_or_cancel_reason` แทน `CANCELLED` (กฎ §4.4)

- `surgical_discharge_id`: รหัสประจำการจำหน่ายสัตว์หลังผ่าตัด ใช้เป็น Primary Key
- `discharge_number`: เลขที่เอกสารจำหน่ายหลังผ่าตัด รูปแบบ `SDC-{YYYY}{MM}{DD}-{NNNN}`
- `branch_id` / `surgery_case_id` / `postop_care_id` / `pet_id` / `owner_id`: สาขา เคสผ่าตัด การดูแลพักฟื้น สัตว์เลี้ยง และเจ้าของ
- `discharge_destination`: ปลายทางหลังจำหน่ายออกจากหน่วยพักฟื้น (`OWNER_HOME` กลับบ้านกับเจ้าของ, `INPATIENT_CARE` ส่งต่อวอร์ดผู้ป่วยใน IPD, `EXTERNAL_REFERRAL` ส่งต่อโรงพยาบาลอื่น, `DECEASED` เสียชีวิต)
- `clinical_discharge_id` / `ipd_admission_id`: จุดเชื่อมไปยังเอกสารจำหน่ายทางคลินิก (`clinical.clinical_discharges`) หรือเลขที่การรับไว้ในโรงพยาบาล (เมื่อมีการออกแบบระบบ Inpatient Care ตามหลัก §6.6 โดยไม่สร้างตาราง Ward/Bed ซ้ำใน Domain 06)
- `assessed_ready_by` / `approved_by` / `discharged_at`: บุคลากรผู้ประเมินความพร้อม สัตวแพทย์ผู้อนุมัติให้จำหน่าย และวันเวลาส่งมอบจริง
- `final_vitals_summary` / `wound_status_at_discharge`: สรุปสัญญาณชีพและสภาพแผลล่าสุด ณ เวลาจำหน่าย
- `take_home_prescription_id`: อ้างอิงใบสั่งยากลับบ้าน (`clinical.prescriptions`) เพื่อเชื่อมกับห้องยาใน Domain 04
- `home_care_instructions` / `diet_activity_restrictions` / `warning_signs_advised`: คำแนะนำดูแลแผล การจำกัดกิจกรรม/อาหาร และอาการผิดปกติที่เจ้าของต้องรีบนำสัตว์กลับมาตรวจ
- `recipient_name` / `recipient_relationship` / `recipient_ownership_id`: ชื่อผู้มารับมอบสัตว์จริง ความสัมพันธ์ และอ้างอิงสิทธิ์จาก `owner.pet_ownerships` (บังคับเมื่อ `discharge_destination = 'OWNER_HOME'`)
- `next_follow_up_date` / `discharge_status`: วันนัดติดตามถัดไป และสถานะเอกสารจำหน่าย (`PENDING`, `APPROVED_FOR_RELEASE`, `DISCHARGED`, `TRANSFERRED_TO_IPD`, `CANCELLED`)
- `notes` / `created_at` / `created_by` / `updated_at` / `updated_by`: หมายเหตุและข้อมูล Audit

#### หมายเหตุ:

1. สถานะ `discharge_status = 'DISCHARGED'` แสดงถึงการส่งมอบสัตว์ทางคลินิกเรียบร้อยแล้ว ไม่ถือว่าเสร็จสิ้นการชำระเงินใน Domain 07 (กฎ §10.6)

### ตาราง `surgery.surgical_follow_ups`

**หน้าที่**: จัดเก็บแผนและการติดตามอาการและการหายของแผลหลังผ่าตัด (Postoperative Follow-up) ทั้งการโทร/แชตติดตามอาการที่บ้าน และการเชื่อมโยงไปยังนัดหมายตรวจแผล/ตัดไหมหรือการตรวจร่างกายจริงใน Domain 02 และ 03 โดยแยกการติดตามทางไกลออกจากการตรวจร่างกายจริงอย่างชัดเจนตามข้อ 3.19

#### โครงสร้าง Field:

| Column                      | Data Type   | Constraint                               |

| `follow_up_id`              | UUID        | PK, NOT NULL                             |
| `follow_up_number`          | VARCHAR(30) | UNIQUE, NOT NULL                         |
| `branch_id`                 | UUID        | FK → core.branches, NOT NULL             |
| `surgery_case_id`           | UUID        | FK → surgery.surgery_cases, NOT NULL     |
| `pet_id`                    | UUID        | FK → owner.pets, NOT NULL                |
| `owner_id`                  | UUID        | FK → owner.owners, NULL                  |
| `follow_up_type`            | ENUM        | NOT NULL                                 |
| `follow_up_mode`            | ENUM        | NOT NULL                                 |

| `completed_at`              | TIMESTAMPTZ | NULL                                     |
| `responsible_employee_id`   | UUID        | FK → hr.employees, NULL                  |
| `appointment_id`            | UUID        | FK → appointment.appointments, NULL      |
| `follow_up_encounter_id`    | UUID        | FK → clinical.clinical_encounters, NULL  |
| `wound_healing_status`      | ENUM        | NULL                                     |

| `updated_by`                | UUID        | FK → hr.employees, NULL                  |

#### ข้อกำหนด:

- `follow_up_id`: รหัสประจำรายการติดตามผลหลังผ่าตัด
- `follow_up_number`: เลขที่การติดตามผล รูปแบบ `SFU-{YYYY}{MM}{DD}-{NNNN}`
- `branch_id` / `surgery_case_id` / `pet_id` / `owner_id`: สาขา เคสผ่าตัดจริง สัตว์เลี้ยง และเจ้าของ
- `follow_up_type`: ประเภทเป้าหมายการติดตาม (`POST_OP_PHONE_CHECK` โทรถามอาการวันถัดไป, `WOUND_RECHECK` นัดตรวจแผล, `SUTURE_REMOVAL` นัดตัดไหม, `ORTHOPEDIC_REASSESSMENT` นัดประเมินกระดูกและข้อ, `IMAGING_RECHECK` นัดเอกซเรย์ติดตามผล, `OTHER`)
- `follow_up_mode`: ช่องทางดำเนินการ (`PHONE_CALL`, `LINE_OA`, `IN_CLINIC_EXAM`, `VIDEO_CALL`) ใช้แยกการติดตามทางไกลออกจากการตรวจร่างกายจริงในคลินิกตามกฎ §3.19
- `scheduled_date` / `completed_at` / `responsible_employee_id`: วันที่ถึงกำหนดติดตาม เวลาดำเนินการเสร็จ และผู้รับผิดชอบ
- `appointment_id` / `follow_up_encounter_id`: อ้างอิงนัดหมายจริง (`appointment.appointments`) และการตรวจร่างกายจริง (`clinical.clinical_encounters`) เมื่อเจ้าของนำสัตว์มาคลินิก
- `wound_healing_status`: สภาพการหายของแผลที่ประเมินได้ (`HEALING_WELL`, `MILD_INFLAMMATION`, `SUSPECTED_INFECTION`, `DEHISCENCE`, `SUTURES_REMOVED`, `NOT_ASSESSED`)
- `appetite_activity_summary` / `pain_status_summary`: อาการกินอาหาร การขับถ่าย และระดับความเจ็บปวดหลังกลับบ้าน
- `abnormality_found` / `escalation_action`: ระบุว่าพบอาการผิดปกติหรือไม่ และการดำเนินการส่งต่อ/นัดหมายเร่งด่วนเมื่อพบปัญหา
- `follow_up_status`: สถานะ (`SCHEDULED`, `CONTACT_ATTEMPTED`, `COMPLETED`, `RESCHEDULED`, `NO_SHOW`, `CANCELLED`)
- `notes` / `created_at` / `created_by` / `updated_at` / `updated_by`: หมายเหตุและข้อมูล Audit

#### หมายเหตุ:

1. หาก `follow_up_mode = 'IN_CLINIC_EXAM'` และสัตว์มาตรวจที่คลินิกแล้ว ควรเชื่อมโยง `follow_up_encounter_id → clinical.clinical_encounters` เพื่อให้ประวัติการรักษาเชื่อมโยงครบถ้วนกับ Domain 03
2. การจำหน่ายสัตว์ใน `surgical_discharges` ไม่ถือว่าการติดตามผลหลังผ่าตัดในตารางนี้เสร็จสิ้นแล้ว (กฎ §5.4)
