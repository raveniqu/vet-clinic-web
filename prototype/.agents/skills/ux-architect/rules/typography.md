# กฎ UX ด้านการจัดตัวอักษรและข้อความ

> **ขอบเขต:** ใช้กฎเหล่านี้กับตัวอักษร ข้อความบนหน้าจอ คอมโพเนนต์ และรูปแบบเนื้อหาทั้งหมดในระบบ
> **ข้อกำหนดส่วนกลาง:** ปฏิบัติตามเกณฑ์ระดับคำสั่ง ลำดับความสำคัญ และขั้นตอนการทำงานใน global.md

---

## TYPO-01 — หลีกเลี่ยงการจัดข้อความกึ่งกลางในเนื้อหาขนาดยาว

**หลักการ:** การจัดข้อความชิดขอบเริ่มต้นช่วยให้มีแนวเริ่มต้นสายตาที่มั่นคง ทำให้อ่านและกวาดสายตาได้รวดเร็วกว่าการจัดกึ่งกลาง

### ข้อกำหนด
- **SHOULD** จัดข้อความขนาดยาว ย่อหน้า คำอธิบายหลายบรรทัด ป้ายกำกับ และเนื้อหาละเอียด ให้ชิดซ้ายเสมอสำหรับภาษาที่อ่านจากซ้ายไปขวา
- **MAY** จัดกึ่งกลางได้เฉพาะหัวข้อสั้น ข้อความแจ้งเตือนหนึ่งถึงสองบรรทัด หรือเนื้อหาบนแบนเนอร์หลักที่มีจุดโฟกัสเดี่ยว
- **MUST NOT** จัดข้อความย่อหน้าขนาดยาวให้อยู่กึ่งกลางเพียงเพราะต้องการความสมมาตรทางสายตา

### แนวทางการนำไปใช้งาน
| สแต็ก หรือ บริบท | รูปแบบที่แนะนำ | ตัวอย่างคลาส โค้ด หรือ โครงสร้าง |
| :--- | :--- | :--- |
| **Tailwind CSS** | ชิดขอบเริ่มต้น | `text-start` หรือ `text-left` |
| **Raw CSS** | จัดชิดจุดเริ่มต้นตามทิศทางภาษา | `text-align: start;` |

**การตรวจสอบความถูกต้อง:** ตรวจดูว่าแนวเริ่มต้นของแต่ละบรรทัดในย่อหน้าตรงกันเป็นเส้นเดียวทางด้านซ้าย

---

## TYPO-02 — หลีกเลี่ยงการจัดข้อความแบบกระจายชิดขอบซ้ายขวา

**หลักการ:** การกระจายข้อความให้ชิดขอบทั้งสองด้านพร้อมกันทำให้เกิดช่องว่างระหว่างคำที่ไม่สม่ำเสมอ ซึ่งทำลายจังหวะการอ่านตามธรรมชาติ

### ข้อกำหนด
- **MUST NOT** ใช้การกระจายข้อความชิดขอบสองข้างเป็นค่าเริ่มต้นสำหรับเนื้อหาทั่วไป
- **SHOULD** จัดชิดซ้ายหรือชิดขอบเริ่มต้นเป็นหลัก
- **ข้อยกเว้น:** อนุญาตให้ใช้เฉพาะงานสิ่งพิมพ์ดิจิทัลเฉพาะทางที่มีข้อกำหนดชัดเจนและผ่านการตรวจทานช่องไฟอย่างละเอียดแล้วเท่านั้น

### แนวทางการนำไปใช้งาน
| สแต็ก หรือ บริบท | รูปแบบที่แนะนำ | ตัวอย่างคลาส โค้ด หรือ โครงสร้าง |
| :--- | :--- | :--- |
| **Tailwind CSS** | หลีกเลี่ยง `text-justify` | ใช้ `text-start` แทน |
| **Raw CSS** | หลีกเลี่ยง `text-align: justify;` | ใช้ `text-align: start;` แทน |

**การตรวจสอบความถูกต้อง:** ระยะห่างระหว่างคำในย่อหน้ามีขนาดสม่ำเสมอตลอดทั้งบรรทัด

---

## TYPO-03 — ป้องกันช่องว่างสีขาวที่เป็นทางน้ำไหลในย่อหน้า

**หลักการ:** ช่องว่างแนวดิ่งหรือแนวทแยงที่เกิดจากช่องไฟระหว่างคำตรงกันหลายบรรทัดต่อเนื่อง รบกวนสมาธิในการอ่านและทำให้เนื้อหาดูแตกกระจาย

### ข้อกำหนด
- **MUST** ยกเลิกการจัดข้อความแบบกระจายชิดขอบซ้ายขวาก่อนเป็นอันดับแรก
- **SHOULD** ทบทวนความกว้างของย่อหน้าและการตัดบรรทัดให้สมดุล
- **MAY** เปิดใช้งานการตัดคำอัตโนมัติตามภาษาที่รองรับ
- **ข้อพิจารณาภาษาไทย:** สำหรับภาษาไทยและภาษาที่ไม่มีการเว้นวรรคระหว่างคำ ต้องตรวจสอบการตัดคำตามพจนานุกรมและบริบทจริง ไม่พึ่งพาการตัดคำภาษาอังกฤษ

### แนวทางการนำไปใช้งาน
| สแต็ก หรือ บริบท | รูปแบบที่แนะนำ | ตัวอย่างคลาส โค้ด หรือ โครงสร้าง |
| :--- | :--- | :--- |
| **Tailwind CSS** | ตัดคำอัตโนมัติพร้อมกำหนดภาษา | กำหนดแอตทริบิวต์ `lang` พร้อมใช้ `text-start hyphens-auto` |
| **Raw CSS** | Hyphenation property | `text-align: start; hyphens: auto;` ร่วมกับแอตทริบิวต์ภาษาบน HTML |

**การตรวจสอบความถูกต้อง:** ย่อหน้าไม่มีรอยแหว่งหรือช่องว่างแนวดิ่งผิดปกติที่เด่นสะดุดตา

## TYPO-04 — กำหนดความยาวต่อบรรทัดให้อ่านสบาย

**หลักการ:** บรรทัดที่ยาวเกินไปทำให้สายตาเคลื่อนกลับไปหาจุดเริ่มบรรทัดถัดไปได้ยาก ส่วนบรรทัดที่สั้นเกินไปทำให้จังหวะการอ่านสะดุดจากการขึ้นบรรทัดใหม่บ่อยเกินไป

### ข้อกำหนด
- **SHOULD** กำหนดความยาวบรรทัดของข้อความภาษาละตินให้อยู่ในช่วง 50 ถึง 75 ตัวอักษรต่อบรรทัดเป็นแนวทางเริ่มต้น
- **MUST NOT** ยืดข้อความย่อหน้ายาวให้กว้างเต็มหน้าจอเดสก์ท็อปขนาดใหญ่
- **ข้อพิจารณาภาษาไทย:** ความกว้างแบบ `ch` วัดจากขนาดตัวอักษรเลขศูนย์ละติน สำหรับข้อความภาษาไทยให้ตรวจดูความกว้างของกล่องข้อความจริง และควบคุมให้อ่านง่ายโดยไม่ยืดยาวเต็มหน้าจอ

### แนวทางการนำไปใช้งาน
| สแต็ก หรือ บริบท | รูปแบบที่แนะนำ | ตัวอย่างคลาส โค้ด หรือ โครงสร้าง |
| :--- | :--- | :--- |
| **Tailwind CSS** | จำกัดความกว้างเนื้อหาย่อหน้า | `max-w-[70ch]` หรือ `max-w-prose` |
| **Raw CSS** | จำกัด max-width | `max-width: 70ch; width: 100%;` |

**การตรวจสอบความถูกต้อง:** ข้อความย่อหน้าบนหน้าจอกว้างไม่ยืดแผ่ขยายตามขนาดหน้าจออย่างไร้ขีดจำกัด

---

## TYPO-05 — หลีกเลี่ยงขอบท้ายย่อหน้าที่เว้าแหว่งจนรบกวนสายตา

**หลักการ:** ขอบด้านท้ายของย่อหน้าที่สั้นยาวไม่สมดุลอย่างรุนแรงทำให้สายตากระตุกขณะกวาดอ่าน

### ข้อกำหนด
- **SHOULD** ใช้คุณสมบัติช่วยตัดบรรทัดที่ทันสมัยเพื่อเฉลี่ยความยาวของบรรทัดให้กลมกลืนขึ้น
- **MUST** จัดการความกว้างของคอนเทนเนอร์เป็นหลัก คุณสมบัติการตัดบรรทัดเป็นเพียงส่วนช่วยเสริม
- **MUST NOT** ใช้การเกลี่ยบรรทัดแบบสมดุลกับบทความยาวทั้งหมดพร้อมกันโดยไม่จำเป็น ให้เน้นใช้กับหัวข้อสั้น

### แนวทางการนำไปใช้งาน
| สแต็ก หรือ บริบท | รูปแบบที่แนะนำ | ตัวอย่างคลาส โค้ด หรือ โครงสร้าง |
| :--- | :--- | :--- |
| **Tailwind CSS** | เกลี่ยหัวข้อและย่อหน้า | หัวข้อ: `text-balance`; ย่อหน้า: `text-pretty` |
| **Raw CSS** | Text-wrap properties | หัวข้อ: `text-wrap: balance;`; ย่อหน้า: `text-wrap: pretty;` |

**การตรวจสอบความถูกต้อง:** บรรทัดสุดท้ายของหัวข้อย่อยไม่เหลือคำโดดเดี่ยวคำเดียว และชายท้ายย่อหน้ามีความเป็นธรรมชาติ

---

## TYPO-06 — กำหนดระยะห่างระหว่างบรรทัดให้เหมาะสม

**หลักการ:** ระยะห่างระหว่างบรรทัดต้องได้สัดส่วนกับขนาดตัวอักษรและความกว้างของบรรทัด เพื่อให้สายตาสามารถแยกแยะบรรทัดออกจากกันได้ชัดเจน

### ข้อกำหนด
- **MUST** เลือกระยะห่างระหว่างบรรทัดให้เหมาะกับขนาดและบทบาทของข้อความ
- **MUST NOT** กำหนดระยะห่างเป็นพิกเซลคงที่ค่าเดียวสำหรับตัวอักษรทุกขนาด
- **ข้อพิจารณาภาษาไทย:** ตัวอักษรภาษาไทยมีพยัญชนะ วรรณยุกต์ และสระทั้งบนและล่าง จึงต้องมีระยะห่างระหว่างบรรทัดมากกว่าตัวอักษรภาษาอังกฤษเล็กน้อย เพื่อป้องกันไม่ให้สระและวรรณยุกต์ชนกัน

### แนวทางสัดส่วนเริ่มต้น
| ชนิดข้อความ | สัดส่วนระยะห่างเริ่มต้นที่แนะนำ |
| :--- | :--- |
| **หัวข้อขนาดใหญ่หลายบรรทัด** | `1.1` ถึง `1.25` |
| **เนื้อหาทั่วไป** | `1.5` ถึง `1.65` (ภาษาไทยมักต้องการอย่างน้อย `1.6`) |
| **เนื้อหาที่มีความกว้างมาก** | `1.65` ถึง `1.8` |
| **ตัวอักษรขนาดเล็กพิเศษ** | ต้องการระยะห่างต่อสัดส่วนมากกว่าข้อความขนาดปกติ |

### แนวทางการนำไปใช้งาน
| สแต็ก หรือ บริบท | รูปแบบที่แนะนำ | ตัวอย่างคลาส โค้ด หรือ โครงสร้าง |
| :--- | :--- | :--- |
| **Tailwind CSS** | Utility ตามระดับข้อความ | หัวข้อ: `leading-tight`; ย่อหน้า: `leading-relaxed` |
| **Raw CSS** | ค่าสัดส่วนแบบไม่มีหน่วยกำกับ | `line-height: 1.6;` |

**การตรวจสอบความถูกต้อง:** วรรณยุกต์และสระในภาษาไทยไม่ซ้อนทับกับบรรทัดบนหรือล่าง และข้อความอ่านสบายตา

## TYPO-07 — จัดลำดับชั้นเนื้อหาให้กวาดสายตาอ่านได้ง่าย

**หลักการ:** ผู้ใช้บนหน้าจอดิจิทัลมักกวาดสายตาหาจุดสำคัญก่อนอ่านรายละเอียดทั้งหมด การสร้างลำดับชั้นทางสายตาที่ชัดเจนช่วยลดเวลาในการค้นหาข้อมูล

### ข้อกำหนด
- **MUST** ใช้แท็กเชิงความหมายตามลำดับ เช่น `<h1>` ถึง `<h6>`, `<p>`, และ `<ul>`
- **SHOULD** สร้างความแตกต่างระหว่างหัวข้อ เนื้อหาหลัก ข้อความรอง และข้อมูลเสริม ด้วยขนาด น้ำหนัก สี และระยะห่าง
- **MUST NOT** สร้างหัวข้อด้วยการใช้ `<div>` ตัวหนาโดยปราศจากแท็กหัวข้อเชิงความหมาย
- **MUST NOT** พึ่งพาเพียงสีเพื่อบอกระดับความสำคัญของข้อความ

### แนวทางการนำไปใช้งาน
| สแต็ก หรือ บริบท | รูปแบบที่แนะนำ | ตัวอย่างคลาส โค้ด หรือ โครงสร้าง |
| :--- | :--- | :--- |
| **Tailwind CSS** | แบ่งระดับด้วยขนาด น้ำหนัก และสี | หัวข้อ: `text-2xl font-bold text-foreground`; ย่อหน้า: `text-base text-foreground/80`; ข้อมูลรอง: `text-sm text-muted-foreground` |
| **Raw CSS** | สไตล์เฉพาะกลุ่มตามคลาส | กำหนด `font-size`, `font-weight`, `line-height` และ `color` แยกตามลำดับชั้น |

**การตรวจสอบความถูกต้อง:** ผู้อ่านสามารถแยกแยะหัวข้อหลัก หัวข้อย่อย และเนื้อหาธรรมดาได้ทันทีตั้งแต่แวบแรกที่มอง

## TYPO-08 — วางหัวข้อให้อยู่ใกล้กับย่อหน้าของตนเอง

**หลักการ:** หัวข้อต้องดูเป็นกลุ่มก้อนเดียวกับเนื้อหาที่มันนำเสนอ ระยะห่างด้านบนของหัวข้อจึงควรมากกว่าระยะห่างด้านล่าง

### ข้อกำหนด
- **MUST** วางหัวข้อให้ใกล้ชิดกับเนื้อหาด้านล่างมากกว่าเนื้อหาของหัวข้อก่อนหน้า
- **MUST NOT** กำหนดระยะขอบบนและล่างเท่ากัน หากทำให้ดูไม่ออกว่าหัวข้อเป็นของย่อหน้าใด
- **SHOULD** คำนึงถึงระยะห่างของเลย์เอาต์แม่เพื่อไม่ให้เกิดระยะห่างซ้ำซ้อน

### แนวทางการนำไปใช้งาน
| สแต็ก หรือ บริบท | รูปแบบที่แนะนำ | ตัวอย่างคลาส โค้ด หรือ โครงสร้าง |
| :--- | :--- | :--- |
| **Tailwind CSS** | ระยะขอบบนมากกว่าขอบล่าง | `mt-10 mb-2` หรือใช้โทเคนระยะห่างของโปรเจกต์ |
| **Raw CSS** | Logical margins | `margin-block-start: 2.5rem; margin-block-end: 0.5rem;` |

**การตรวจสอบความถูกต้อง:** สายตาสามารถจับคู่หัวข้อกับเนื้อหาบริวารด้านล่างได้อย่างเป็นธรรมชาติโดยไม่สับสน

---

## TYPO-09 — ใช้สีข้อความที่นุ่มนวลสบายตา

**หลักการ:** การใช้สีดำสนิทบนพื้นขาวล้วน หรือสีขาวสนิทบนพื้นดำสนิท อาจสร้างความเปรียบต่างที่จัดจ้านเกินไปจนทำให้ตาล้า

### ข้อกำหนด
- **SHOULD** ใช้สีเทาเข้มเกือบดำสำหรับพื้นสว่าง และสีเทาอ่อนเกือบขาวสำหรับพื้นมืด
- **MUST** รักษาอัตราส่วนความเปรียบต่างของสีให้ผ่านเกณฑ์มาตรฐานการเข้าถึงเสมอ
- **MUST NOT** ลดความเข้มของตัวหนังสือจนซีดจางเกินไปเพียงเพราะต้องการความสวยงาม

### แนวทางการนำไปใช้งาน
| สแต็ก หรือ บริบท | รูปแบบที่แนะนำ | ตัวอย่างคลาส โค้ด หรือ โครงสร้าง |
| :--- | :--- | :--- |
| **Tailwind CSS** | สีกลุ่ม slate หรือ zinc | เนื้อหาหลัก: `text-foreground`; ข้อความรอง: `text-muted-foreground` |
| **Raw CSS** | ค่าสีที่ผ่านการปรับความเข้ม | เนื้อหาหลัก: `color: #1e293b;`; ข้อความรอง: `color: #475569;` |

**การตรวจสอบความถูกต้อง:** ข้อความอ่านง่าย ไม่แสบตา และผ่านเกณฑ์ความเปรียบต่างอย่างน้อย 4.5:1

---

## TYPO-10 — เว้นระยะเส้นใต้ของลิงก์ไม่ให้ชิดตัวอักษรเกินไป

**หลักการ:** ลิงก์ที่อยู่ร่วมกับเนื้อหาต้องสังเกตได้ว่าเป็นจุดที่กดได้ และเส้นใต้ต้องไม่ตัดผ่านหรือเบียดติดหางตัวอักษรจนทำให้อ่านยาก

### ข้อกำหนด
- **MUST** แสดงจุดสังเกตของลิงก์อย่างชัดเจน โดยเส้นใต้เป็นรูปแบบมาตรฐานที่ปลอดภัยที่สุดในเนื้อหาย่อหน้า
- **SHOULD** เว้นระยะห่างระหว่างตัวหนังสือกับเส้นใต้เล็กน้อย และปรับความหนาของเส้นให้พอดี
- **MUST** คงจุดสังเกตโฟกัสของคีย์บอร์ดที่ชัดเจนเมื่อผู้ใช้เลื่อนแท็บมาที่ลิงก์
- **MUST NOT** พึ่งพาความแตกต่างของสีเพียงอย่างเดียวในการสื่อสารความเป็นลิงก์ในย่อหน้า

### แนวทางการนำไปใช้งาน
| สแต็ก หรือ บริบท | รูปแบบที่แนะนำ | ตัวอย่างคลาส โค้ด หรือ โครงสร้าง |
| :--- | :--- | :--- |
| **Tailwind CSS** | ขยับเส้นใต้และกำหนดจุดโฟกัส | `underline underline-offset-4 decoration-1 focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-ring` |
| **Raw CSS** | กำหนด offset ของเส้นใต้ | `text-decoration-line: underline; text-underline-offset: 0.2em;` |

**การตรวจสอบความถูกต้อง:** เส้นใต้ไม่ตัดผ่านสระล่างในภาษาไทย หรือหางตัวอักษร เช่น g, y, p ในภาษาอังกฤษ

## TYPO-11 — หลีกเลี่ยงการเน้นข้อความมากเกินไป

**หลักการ:** หากทุกอย่างถูกเน้นพร้อมกัน จะไม่มีสิ่งใดโดดเด่นเลย การเน้นข้อความต้องใช้เท่าที่จำเป็นและมีจุดมุ่งหมาย

### ข้อกำหนด
- **SHOULD** ใช้วิธีเน้นข้อความเพียงหนึ่งหรือสองรูปแบบร่วมกัน เช่น ตัวหนา หรือการเปลี่ยนสีเล็กน้อย
- **AVOID** การผสมตัวหนา ตัวเอียง ตัวพิมพ์ใหญ่ สีสด ขีดเส้นใต้ และพื้นหลังไฮไลต์พร้อมกันในจุดเดียว
- **MUST NOT** เน้นข้อความกระจายตัวมากเกินไปจนหน้าจอดูรก
- **MUST** ใช้แท็ก `<strong>` หรือ `<em>` เมื่อต้องการสื่อความหมายเชิงการเน้นย้ำจริง

### แนวทางการนำไปใช้งาน
| สแต็ก หรือ บริบท | รูปแบบที่แนะนำ | ตัวอย่างคลาส โค้ด หรือ โครงสร้าง |
| :--- | :--- | :--- |
| **Tailwind CSS** | เน้นด้วยน้ำหนักตัวอักษรที่พอเหมาะ | `font-semibold text-foreground` |
| **Raw CSS** | ใช้ Semantic tag พร้อมน้ำหนักที่เหมาะสม | `strong { font-weight: 600; color: #0f172a; }` |

**การตรวจสอบความถูกต้อง:** จุดที่ต้องการเน้นสะดุดสายตาได้ทันทีโดยไม่สร้างความรำคาญในการอ่านย่อหน้าโดยรวม

## TYPO-12 — เลือกรูปแบบตัวเลขให้เหมาะกับบริบท

**หลักการ:** ตัวเลขในตารางและตัวเลขที่เปลี่ยนแปลงตลอดเวลาจำเป็นต้องมีความกว้างคงที่เพื่อป้องกันการสั่นไหว ส่วนตัวเลขในเนื้อหาทั่วไปควรกลมกลืนกับข้อความ

### ข้อกำหนด
- **SHOULD** ใช้ตัวเลขแบบความกว้างคงที่สำหรับตาราง ตัววัดสถิติ ราคา และตัวเลขนับถอยหลัง
- **SHOULD** ใช้ตัวเลขแบบความกว้างตามสัดส่วนสำหรับเนื้อหาทั่วไปในย่อหน้า
- **MUST NOT** สรุปว่าแบบอักษรทุกตัวรองรับฟีเจอร์ตัวเลขของ OpenType เสมอ ต้องทดสอบการแสดงผลจริง

### รูปแบบตัวเลขและการใช้งาน
| การใช้งาน | Tailwind CSS | Raw CSS |
| :--- | :--- | :--- |
| **ตาราง ราคา สถิติ** | `tabular-nums lining-nums` | `font-variant-numeric: tabular-nums lining-nums;` |
| **ข้อความย่อหน้าทั่วไป** | `proportional-nums lining-nums` | `font-variant-numeric: proportional-nums lining-nums;` |

**การตรวจสอบความถูกต้อง:** ตัวเลขในตารางเรียงหลักตรงกันในแนวดิ่ง และตัวเลขที่เปลี่ยนค่าไม่ทำให้ความกว้างของข้อความกระตุก

## รายการตรวจสอบก่อนส่งมอบงาน

- [ ] **TYPO-01:** ย่อหน้ายาวจัดชิดขอบเริ่มต้นเสมอ ไม่มีการจัดกึ่งกลาง
- [ ] **TYPO-02:** ไม่มีการใช้การจัดกระจายชิดขอบซ้ายขวากับเนื้อหาทั่วไป
- [ ] **TYPO-03:** ไม่มีช่องว่างผิดปกติในย่อหน้า และตรวจสอบการตัดคำภาษาไทยแล้ว
- [ ] **TYPO-04:** ความยาวบรรทัดของย่อหน้าอยู่ในเกณฑ์ที่สบายตา ไม่ยืดกว้างเต็มจอ
- [ ] **TYPO-05:** ปลายบรรทัดมีความเป็นธรรมชาติ ไม่มีคำโดดเดี่ยวคำเดียวในบรรทัดสุดท้าย
- [ ] **TYPO-06:** ระยะห่างระหว่างบรรทัดเหมาะสม สระและวรรณยุกต์ภาษาไทยไม่ชนกัน
- [ ] **TYPO-07:** ลำดับชั้นหัวข้อย่อยและเนื้อหาชัดเจน และใช้โครงสร้างแท็กถูกต้อง
- [ ] **TYPO-08:** หัวข้ออยู่ใกล้ชิดกับย่อหน้าของตนเองมากกว่าเนื้อหาด้านบน
- [ ] **TYPO-09:** สีตัวอักษรอ่านสบายตา และผ่านเกณฑ์ความเปรียบต่างของสี
- [ ] **TYPO-10:** เส้นใต้ของลิงก์เว้นระยะห่างพอเหมาะ และมีจุดโฟกัสคีย์บอร์ดชัดเจน
- [ ] **TYPO-11:** การเน้นข้อความใช้เฉพาะจุดสำคัญ ไม่ปะปนหลายรูปแบบจนเกินไป
- [ ] **TYPO-12:** ตัวเลขในตารางและสถิติใช้รูปแบบความกว้างคงที่
